Chips use per-course tonal pairs derived from the wallpaper palette, so they stay legible in both themes without hardcoding brand colors. Everything else is a Material 3 role, which is what lets Pixel's dynamic color recolor the widget automatically when you change wallpaper.

How it maps to Glance

// DueSoonWidget.kt — the structure this mockup is drawn from
@Composable
fun DueSoonContent(state: DueSoonState) {
  Column(
    modifier = GlanceModifier
      .fillMaxSize()
      .background(GlanceTheme.colors.surfaceContainer)
      .cornerRadius(28.dp)
      .padding(16.dp)
  ) {
    Header("Due soon", state.count)

    state.items.take(3).forEach { item ->
      Row(
        verticalAlignment = Alignment.CenterVertically,
        modifier = GlanceModifier.padding(vertical = 4.dp)
      ) {
        CheckBox(
          checked = item.done,
          onCheckedChange = actionRunCallback<ToggleDoneAction>(
            parameters = actionParametersOf(ItemIdKey to item.id)
          )
        )
        Column(modifier = GlanceModifier.defaultWeight()) {
          Text(
            item.title,
            style = TextStyle(fontSize = 14.sp, fontWeight = FontWeight.Medium),
            maxLines = 1
          )
          Text(
            "${item.courseCode} · ${item.dueLabel}",
            style = TextStyle(fontSize = 12.sp, color = GlanceTheme.colors.onSurfaceVariant)
          )
        }
        Text(item.relative, style = TextStyle(fontSize = 12.sp))
        Image(
          provider = ImageProvider(R.drawable.ic_more_horiz),
          contentDescription = "More",
          modifier = GlanceModifier.clickable(actionStartActivity<TriageActivity>())
        )
      }
    }
  }
}

Two Glance constraints to design around: there is no long-press, so the ⋯ is a real button; and collection widgets are flaky on some launchers, so the 4×2 layout is a fixed take(3) column with a “+2 more” row rather than a scrollable list.
